## How to Run Locally

No build step required. Just open `index.html` in any modern web browser:

1. Clone the repo:
   ```
   git clone <repo-url>
   cd webdev-final
   ```
2. Open `index.html` in a browser (double-click the file, or right-click → "Open with" → your browser).

That's it.
